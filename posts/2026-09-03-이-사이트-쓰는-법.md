이 사이트는 **브라우저에서 바로 글을 쓰고 발행하는 곳**입니다.
터미널을 열거나 파일을 직접 만질 필요가 없습니다.

## 처음 한 번만 할 일

글을 저장하려면 이 브라우저가 저장소에 쓸 권한이 있다고 증명해야 합니다.
우측 상단 **⚙ 설정**을 눌러 GitHub 토큰을 등록해 주세요. 발급 방법도 그 안에 적어두었습니다.

> 💡 토큰은 이 기기의 브라우저에만 저장됩니다. 저장소에는 올라가지 않으니, 사이트에 방문한 다른 사람은 글을 고칠 수 없습니다.

토큰을 만들 때 권한은 이렇게 좁게 주는 것이 안전합니다.

- 대상 저장소: 이 저장소 **하나만**
- 권한: **Contents** 를 *Read and write* 로 **하나만**

## 글 쓰는 흐름

1. 위쪽 **새 글** 을 누릅니다
2. 제목과 본문을 씁니다
3. **발행** 을 누릅니다

발행하면 글이 `posts/` 폴더에 마크다운 파일로 커밋되고, 30초쯤 뒤 목록에 나타납니다.
아직 정리가 안 된 글은 **초안 저장** 을 눌러 두었다가 나중에 이어 쓰면 됩니다.

## 서식 넣기

본문에서 `/` 를 누르면 서식 메뉴가 열립니다. 제목, 목록, 인용, 코드 블록, 표 같은 것을 골라 넣을 수 있습니다.
마크다운 문법을 직접 써도 똑같이 동작합니다.

### 이런 것들이 됩니다

- **굵게**, *기울임*, ~~취소선~~, `인라인 코드`
- 목록과 번호 목록
- [링크](https://github.com)

- [x] 체크된 항목
- [ ] 아직 안 한 항목

> 인용문은 이렇게 표시됩니다.

| 단축키 | 하는 일 |
| --- | --- |
| `/` | 서식 메뉴 열기 |
| `Ctrl` + `S` | 초안 저장 |
| `Ctrl` + `Enter` | 발행 |
| `Ctrl` + `K` | 목록에서 검색 |

```js
// 코드 블록도 그대로 보입니다
console.log('안녕하세요');
```

이미지는 **붙여넣기(Ctrl+V)** 로 올릴 수 있습니다. 자동으로 크기를 줄여 저장소에 올린 뒤 본문에 삽입합니다.

## 글이 어디에 저장되나요

글 하나가 파일 하나입니다. 위쪽 메타데이터와 본문으로 이루어져 있습니다.

```text
posts/2026-09-03-이-사이트-쓰는-법.md
```

전부 평범한 텍스트 파일이라 다른 도구로 옮겨가기도 쉽고, 수정 이력이 git에 그대로 남습니다.
글 상단의 **기록** 버튼을 누르면 그 글이 언제 어떻게 바뀌었는지 볼 수 있습니다.
